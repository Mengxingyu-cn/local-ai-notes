便携版 Node.js 放置说明（零安装，新手推荐）
==========================================

本文件夹用于存放便携版 Node.js —— 不需要安装，放进来就能用。

【怎么放】
1. 浏览器打开：https://nodejs.org/en/download
2. 在 Windows 部分选择"Windows Binary (.zip)"下载
3. 解压后你会得到一个类似 node-v22.x.x-win-x64 的文件夹
4. 把该文件夹【里面的所有内容】（node.exe 以及其余文件）复制到本文件夹（node/）里
5. 确认本文件夹下直接能看到 node.exe（不是多包一层文件夹）
6. 回到上级目录，双击 start.bat 即可启动

【要求】
- Node.js 18 或更高版本（推荐下载页面默认的最新正式版）
- 复制前如果 node 文件夹里已有旧文件，先删掉再复制，避免新旧混用

【常见问题】
- 双击 start.bat 提示"使用系统安装的 Node.js"：说明本文件夹里没有 node.exe，
  按上面步骤放入即可，脚本会自动优先使用便携版。
- 无需配置任何环境变量，脚本会自动找到本文件夹里的 node.exe。
